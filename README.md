# 🕒 Sistema de Ponche de Pasantía

Sistema web desarrollado para registrar la **entrada y salida de estudiantes durante su pasantía**.

El sistema permite seleccionar el lugar de pasantía, registrar la hora de entrada, registrar la hora de salida y calcular automáticamente el tiempo realizado.

---

## 📌 Descripción

Este proyecto fue creado como un sistema sencillo de control de asistencia para estudiantes que se encuentran realizando pasantías.

Cada estudiante puede escribir su nombre, seleccionar la empresa donde realiza su pasantía y registrar su entrada y salida.

Los registros realizados aparecen en un historial dentro de la misma página.

> Actualmente los datos no se almacenan permanentemente.  
> Si la página se actualiza o se cierra, el historial se reinicia.

---

## 🚀 Funciones

- 👤 Registrar nombre del estudiante.
- 🏢 Seleccionar lugar de pasantía.
- 🟢 Registrar hora de entrada.
- 🔴 Registrar hora de salida.
- 📅 Mostrar fecha actual.
- 🕒 Reloj en tiempo real.
- ⏱️ Calcular tiempo realizado.
- 📋 Mostrar historial de ponches.
- 🗑️ Limpiar historial.
- 📱 Diseño adaptable para computadora y dispositivos móviles.
